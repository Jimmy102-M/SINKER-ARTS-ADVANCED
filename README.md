# SINKER ARTS

**Tattoo, piercing, and professional studio supplies in Nakuru, Kenya.**

Explore tattoo work and design ideas, request an appointment, or browse studio supplies from one responsive page.

## Live Site

[Open the current site preview](https://htmlpreview.github.io/?https://github.com/Jimmy102-M/SINKER-ARTS-ADVANCED/blob/main/sinker.html)

The preview is served from the public GitHub repository. The existing [SINKER ARTS website](https://sinkerarts.pages.dev/) is also online.

## What You Can Do

- Browse tattoo and piercing services and starting prices.
- View tattoo work and design references.
- Select a design to prefill it in the appointment form.
- Send appointment requests to SINKER ARTS on WhatsApp.
- Search and filter the supplies catalog by category.
- Add products to a cart and prepare an order message for WhatsApp.
- Use the responsive layout on desktop and mobile.

## Run Locally

The site has no build step or package dependencies. With Python installed, run this from the project folder:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000/sinker.html](http://localhost:8000/sinker.html).

You can also open `sinker.html` directly in a browser, though a local server is more representative of hosting.

## How It Works

This is a static front-end project built with HTML, CSS, and vanilla JavaScript. Product search, category filters, design selection, and cart updates happen in the browser. Booking and checkout prepare WhatsApp messages for **+254 706 409 772**.

There is no backend, online payment processing, or server-side order storage. Cart contents are temporary and are cleared when the page is reloaded. Product and gallery images are loaded from the SINKER ARTS website, so an internet connection is needed to display them.

Prices shown are starting prices. Final tattoo quotes and appointments are confirmed directly with SINKER ARTS.
